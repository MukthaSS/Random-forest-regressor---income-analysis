# 🛒 Super Market Sales Analysis

Analyze supermarket sales data to uncover trends, performance metrics, and actionable insights.

---

## 📌 Project Overview

This project explores a real-world supermarket dataset to:
- Clean and preprocess sales data
- Perform exploratory data analysis (EDA)
- Visualize trends in sales, profits, customer behavior, and product categories
- Build dashboards and visual reports for informed decision-making

---

## 🚀 Features

- **Data Cleaning & Preprocessing**  
  Handle missing values, fix data types, and remove duplicates for reliable analysis.

- **Exploratory Data Analysis**  
  Investigate key metrics: total sales, profits, customer counts, and trends over time.

- **Category & Regional Analysis**  
  Compare sales by product type and geographic region to identify top-performing segments.

- **Customer Behavior Insights**  
  Analyze metrics like basket size, purchase frequency, and average transaction value.

- **Interactive Dashboards**  
  Use Jupyter notebooks and, optionally, Tableau for rich visual analysis and storytelling.

- **Predictive Modeling (Optional)**  
  Predict sales or customer segments using machine learning models like Random Forest.

## 🗂️ Data Structure

Typical columns in `SuperMarket Analysis.csv`:

| Column              | Description                         |
|---------------------|-------------------------------------|
| `Order ID`          | Unique transaction identifier       |
| `Product`           | Product name                        |
| `Category`          | Product category                    |
| `Sales`             | Sales amount for the transaction    |
| `Profit`            | Profit earned                       |
| `Quantity`          | Number of items sold                |
| `Order Date`        | Date of the transaction             |
| `Region`            | Supermarket location/region         |
| `Customer Segment`  | Customer type (e.g., Consumer, Corporate) |

*Update column list as needed based on your dataset*

## 📥 Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/MukthaSS/Super_Market_analysis.git
    cd Super_Market_analysis
    ```

2. Create a virtual environment and install dependencies:
    ```bash
    python3 -m venv venv
    source venv/bin/activate   # On Windows: venv\Scripts\activate
    pip install -r requirements.txt
    ```
